# Midnight Airmail

A paper-collage poker roguelike. A girl at her lit window folds every letter into a paper airplane; play poker hands to light the town's windows before daybreak.

Play: https://SamSprin.github.io/midnight-airmail/

Run locally: `python -m http.server 8765`, then open http://127.0.0.1:8765/
Tests: `node tests/run-tests.js` and `node tests/content-tests.js`
Design spec: [DESIGN.md](DESIGN.md)
